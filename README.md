# Sales Performance Analysis Dashboard (2024–2025)

## Project Overview

This project analyses sales performance for a retail business using Microsoft Excel. The purpose was to transform raw sales data into meaningful business insights that can support management decision-making.

The analysis focuses on revenue, profit, product performance, regional performance, sales representatives, sales channels and monthly sales trends.

## Business Objectives

The main objectives were to:
-	Analyse overall revenue and profit performance.
-	Identify the top-performing and lowest-performing products.
-	Evaluate sales performance across different regions.
-	Compare sales representative performance.
-	Analyse the performance of different sales channels.
-	Identify monthly sales trends.
-	Develop business insights and recommendations based on the findings.

## Tools and Techniques
Tool: Microsoft Excel

Skills and techniques applied:
-	Data cleaning and preparation
-	Excel formulas and functions
-	Missing value identification
-	Data standardisation using TRIM and PROPER
-	Calculated columns
-	Excel Tables
-	PivotTables
-	PivotCharts
-	Dashboard development
-	Data analysis and interpretation
-	Business insights and recommendations

## Dataset Description
The dataset contains 1,200 sales transaction records covering 2024 and 2025.
Key fields include:
-	Order ID
-	Order Date
-	Region
-	City
-	Sales Representative
-	Category
-	Product
-	Quantity
-	Unit Price
-	Discount
-	Unit Cost
-	Sales Channel
-	Customer Segment
-	Payment Method

The dataset was used to calculate revenue, cost, profit and profit margin.
